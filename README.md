# Parcial 2 - Informática 2

Sistema de monitoreo neurológico desarrollado en Python.

## Funcionalidades

- Lectura y análisis de archivos CSV.
- Información estadística mediante `info()` y `describe()`.
- Gráficos de señales EEG.
- Diferencia interhemisférica entre canales.
- Lectura de archivos MAT.
- Operaciones entre cuatro canales.
- Análisis estadístico de matrices 3D.
- Visualización mediante gráficos y boxplots.

## Archivos principales

- `clases.py`: contiene las clases y funciones principales.
- `main.py`: contiene el menú y la ejecución del programa.

## Librerías utilizadas

- NumPy
- Pandas
- SciPy
- Matplotlib

## Ejecución

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar:

```bash
python main.py
